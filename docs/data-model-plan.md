# Data Model Plan

## Core Entities

### Tenant

Represents one migration agency using the SaaS platform.

Important fields:

- `id`
- `name`
- `slug`
- `brandColor`
- `retentionYears`
- `createdAt`

### User

Represents staff users and client portal users.

Important fields:

- `id`
- `tenantId`
- `name`
- `email`
- `role`
- `status`
- `lastLoginAt`
- `createdAt`

Roles:

- `ASUN_ADMIN`
- `AGENCY_ADMIN`
- `RMA`
- `CASE_OFFICER`
- `FINANCE`
- `CLIENT`

### Client

Represents a migration client.

Important fields:

- `id`
- `tenantId`
- `name`
- `email`
- `dateOfBirth`
- `nationality`
- `passportEncrypted`
- `passportMasked`
- `consentStatus`
- `conflictCheckStatus`
- `portalActive`
- `createdAt`

### FamilyLink

Links clients and dependants.

Important fields:

- `id`
- `tenantId`
- `primaryClientId`
- `dependantClientId`
- `relationship`

### Matter

Represents a visa application or case.

Important fields:

- `id`
- `tenantId`
- `clientId`
- `visaSubclass`
- `title`
- `stage`
- `trn`
- `primaryAgentId`
- `caseOfficerId`
- `openedAt`
- `closedAt`

Stages:

- `INTAKE`
- `DOCUMENTS`
- `LODGEMENT`
- `CASE_OFFICER_REQUEST`
- `DECISION`
- `ARCHIVED`

### MatterKeyDate

Tracks important dates.

Important fields:

- `id`
- `tenantId`
- `matterId`
- `type`
- `label`
- `date`
- `alertBeforeDays`

### Task

Represents work assigned to staff.

Important fields:

- `id`
- `tenantId`
- `matterId`
- `assigneeId`
- `title`
- `description`
- `status`
- `dueOn`
- `completedAt`

Statuses:

- `OPEN`
- `BLOCKED`
- `DONE`
- `SNOOZED`

### ChecklistItem

Represents required steps or documents for a matter.

Important fields:

- `id`
- `tenantId`
- `matterId`
- `title`
- `category`
- `status`
- `required`
- `dueOn`
- `verifiedById`
- `verifiedAt`

### Document

Represents uploaded document metadata.

Important fields:

- `id`
- `tenantId`
- `matterId`
- `checklistItemId`
- `title`
- `fileName`
- `fileType`
- `fileSize`
- `storageKey`
- `status`
- `uploadedById`
- `verifiedById`
- `createdAt`

Statuses:

- `REQUESTED`
- `RECEIVED`
- `VERIFIED`
- `REJECTED`
- `SIGNING`

### SignatureEnvelope

Tracks e-signature requests.

Important fields:

- `id`
- `tenantId`
- `documentId`
- `provider`
- `providerEnvelopeId`
- `status`
- `sentAt`
- `completedAt`

### Invoice

Represents billing sent to a client.

Important fields:

- `id`
- `tenantId`
- `matterId`
- `clientId`
- `number`
- `status`
- `subtotal`
- `tax`
- `total`
- `dueOn`
- `sentAt`
- `paidAt`

Statuses:

- `DRAFT`
- `SENT`
- `OVERDUE`
- `PAID`

### Payment

Represents payment records from Stripe or manual entry.

Important fields:

- `id`
- `tenantId`
- `invoiceId`
- `provider`
- `providerPaymentId`
- `amount`
- `status`
- `paidAt`

### Message

Represents secure communication.

Important fields:

- `id`
- `tenantId`
- `matterId`
- `senderId`
- `visibility`
- `body`
- `createdAt`

### WorkflowTemplate

Defines visa subclass workflow templates.

Important fields:

- `id`
- `tenantId`
- `visaSubclass`
- `name`
- `description`
- `active`

### WorkflowTemplateItem

Defines tasks and checklist items generated by a template.

Important fields:

- `id`
- `templateId`
- `type`
- `title`
- `description`
- `stage`
- `dueOffsetDays`
- `required`

### AuditEvent

Records important compliance events.

Important fields:

- `id`
- `tenantId`
- `actorUserId`
- `entityType`
- `entityId`
- `action`
- `metadata`
- `ipAddress`
- `createdAt`

## Relationship Summary

```txt
Tenant -> Users
Tenant -> Clients
Client -> Matters
Matter -> Tasks
Matter -> ChecklistItems
ChecklistItem -> Documents
Document -> SignatureEnvelope
Matter -> Invoices
Invoice -> Payments
Matter -> Messages
Tenant -> WorkflowTemplates
Tenant -> AuditEvents
```
